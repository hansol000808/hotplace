# 국내 핫플 여행지

전국 6개 권역의 여행지 24곳을 건축·자연·꽃밭·카페 테마로 살펴보는 정적 웹사이트입니다. 여행지 카드를 선택하면 사진, 영상, 주소와 운영 정보 등을 담은 상세 페이지를 볼 수 있습니다.

**Standard Web Technology 프로젝트 · cau-swt2025**

- 저장소: [hansol000808/cau-swt2025](https://github.com/hansol000808/cau-swt2025)
- 구현: HTML, CSS, JavaScript
- 기반 템플릿: BootstrapMade의 MyResume

## 주요 기능

- **권역별 탐색:** 수도권·강원권·충청권·경상권·전라권·제주권으로 이동하는 내비게이션
- **테마 필터:** 각 권역에서 `All`, `#건축`, `#자연`, `#꽃밭`, `#카페`로 카드 필터링
- **상세 보기:** 여행지 카드를 누르면 GLightbox로 별도 HTML 페이지 표시
- **사진·영상 콘텐츠:** Swiper 사진 슬라이더와 YouTube 임베드
- **화면 효과:** 타이핑 효과, 스크롤 애니메이션, 맨 위로 이동 버튼
- **반응형 구성:** Bootstrap 그리드와 모바일 내비게이션

여행지 정보는 HTML에 직접 작성되어 있습니다. 검색 서버나 데이터베이스를 사용하는 구조는 아닙니다.

## 로컬에서 실행하기

핵심 여행지 탐색 기능은 정적 파일로 구성되어 있어 별도의 빌드나 npm 패키지 설치가 필요하지 않습니다. 아래는 Python 3의 정적 파일 서버를 사용하는 방법입니다.

### 1. 저장소 내려받기

Git이 설치된 환경에서 다음 명령을 실행합니다. GitHub의 **Code → Download ZIP**으로 내려받아 압축을 풀어도 됩니다.

```sh
git clone https://github.com/hansol000808/cau-swt2025.git
cd cau-swt2025
```

### 2. 정적 파일 서버 실행

`index.html`이 있는 저장소 루트에서 실행합니다.

Windows:

```powershell
py -3 -m http.server 8000 --bind 127.0.0.1
```

macOS / Linux:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

### 3. 브라우저에서 열기

[http://127.0.0.1:8000](http://127.0.0.1:8000)에 접속합니다. 서버를 종료하려면 터미널에서 `Ctrl+C`를 누릅니다.

Google Fonts와 YouTube 등 외부 콘텐츠를 불러오려면 인터넷 연결이 필요합니다. 위 서버는 정적 페이지 확인용이며 PHP를 실행하지 않습니다.

## 동작 흐름과 주요 코드

1. `index.html`이 공통 스타일과 외부 라이브러리, `assets/js/main.js`를 불러옵니다.
2. `main.js`의 즉시 실행 함수가 이벤트와 UI 기능을 초기화합니다.
3. 페이지 로드 후 권역별 Isotope 인스턴스가 카드를 배치합니다. 필터 클릭 시 `data-filter` 값을 `arrange()`에 전달합니다.
4. `.portfolio-details-lightbox` 링크를 선택하면 GLightbox가 해당 `details_*.html`을 표시합니다.
5. 상세 페이지의 `.portfolio-details-slider`는 Swiper로 초기화됩니다.

`main.js`의 주요 헬퍼는 `select()`와 `on()`이며, `navbarlinksActive()`는 현재 스크롤 위치에 맞춰 메뉴를 표시하고 `scrollto()`는 섹션 이동을 처리합니다.

## 콘텐츠 수정하기

| 수정할 내용 | 위치 |
| --- | --- |
| 여행지 카드, 주소 요약, 테마 분류 | `index.html` |
| 상세 설명, 운영 정보, 사진·영상 링크 | 해당 `details_*.html` |
| 사진 파일 | `assets/img/<권역>/` |
| 색상, 여백, 화면 크기별 스타일 | `assets/css/style.css` |
| 필터, 애니메이션, 슬라이더 동작 | `assets/js/main.js` |

기존 권역에 여행지를 추가할 때는 같은 권역의 카드와 상세 페이지 구조를 참고합니다. 카드의 `<권역>-item` 클래스와 `filter-architecture`, `filter-nature`, `filter-flower`, `filter-cafe` 중 해당 분류를 지정하고 상세 페이지 링크와 이미지 경로를 맞춥니다.

새로운 권역을 추가하려면 HTML뿐 아니라 `main.js`의 권역별 Isotope 초기화와 관련 스타일도 함께 확인해야 합니다.

## 현재 상태와 개선 과제

이 README는 2026-09-23 기준 `main` 브랜치의 구현 내용을 설명합니다. 현재 저장소에는 자동화 테스트나 CI 설정이 없습니다.

### 알려진 제약

- 메인 페이지에서 참조하는 여행지 이미지 24개의 원본 용량 합계가 약 24MB이며, 이미지 지연 로딩이 적용되어 있지 않습니다.
- 권역별 필터 초기화와 상세 페이지 마크업이 반복되어 콘텐츠가 늘면 여러 파일을 함께 수정해야 합니다.
- 필터와 모바일 메뉴의 키보드 접근성, 사진 대체 텍스트를 보완할 필요가 있습니다.
- `forms/contact.php`는 현재 메인 화면에 연결된 기능이 아닙니다. 수신 주소가 예제 값이고 필요한 `php-email-form.php`도 포함되어 있지 않아, 문의 전송 기능이 준비된 상태는 아닙니다.

### 개선 후보

- [ ] 여행지 썸네일 크기 조정, 이미지 포맷 최적화와 지연 로딩
- [ ] 키보드로 조작 가능한 필터·메뉴와 이미지 설명 제공
- [ ] 여행지 데이터를 분리하고 공통 상세 페이지 구조 도입
- [ ] 권역별 필터 초기화 로직을 공통 함수로 통합
- [ ] 링크·이미지 경로 검사 및 주요 탐색 흐름 테스트 추가

위 항목은 향후 개선 후보이며 현재 구현된 기능은 아닙니다.
